# Contenido editable

Esta carpeta agrupa los textos que se cambian con más frecuencia.

## Textos de páginas

Edita `site-content.ts` para cambiar textos de la web:

- `home`: portada
- `how`: página "Cómo funciona"
- `areas`: página "Ámbitos"
- `sessions`: página "Sesiones"
- `about`: página "Sobre mí"
- `events`: página "Eventos"
- `journal`: listado del blog
- `faq`: preguntas frecuentes
- `contact`: página de contacto
- `legal`: textos legales
- `footer`: pie de página

Cada idioma tiene su bloque:

- `es`: castellano
- `va`: valenciano
- `en`: inglés

## Blog

Edita `blog-posts.ts` para añadir o cambiar artículos completos.

Cada artículo tiene:

- `slug`: parte final de la URL
- `title`: título
- `excerpt`: resumen
- `date`: fecha
- `blocks`: contenido del artículo

Tipos de bloque disponibles:

- `lead`: entradilla
- `p`: párrafo
- `h2`: subtítulo
- `quote`: cita destacada
- `note`: nota final

## Ajustes

Edita `site-settings.ts` para cambiar datos técnicos que no son diseño:

- enlace del calendario de reservas
- email del programa para dejar de fumar
- texto inicial del email de dejar de fumar
